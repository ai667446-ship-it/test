# beat_sync — 楽曲に合わせた自動動画編集

楽曲のビート（拍）を解析して、動画・画像素材をビートのタイミングで自動的にカット・つなぎ合わせ、
曲付きの動画を書き出すスクリプトです。

## 必要なもの

- Python 3.9 以上
- numpy (`pip install numpy`)
- ffmpeg / ffprobe（PATH 上にあること）

## 使い方

```bash
# 素材フォルダに動画 (mp4/mov/mkv/webm...) や画像 (jpg/png...) を入れておく
python3 beat_sync.py --music song.mp3 --clips clips/ --out output.mp4
```

### よく使う例

```bash
# 縦長 (TikTok / リール向け)、サビ 45秒目から 30秒間、毎拍カット + 白フラッシュ
python3 beat_sync.py --music song.mp3 --clips clips/ --out reel.mp4 \
    --aspect 9:16 --start 45 --duration 30 --beats-per-cut 1 --flash

# 横長 (YouTube 向け)、1小節 (4拍) ごとにゆったり切り替え、素材はファイル名順、ズーム演出
python3 beat_sync.py --music song.mp3 --clips clips/ --out mv.mp4 \
    --beats-per-cut 4 --order sequential --zoom

# 書き出す前にテンポとカット位置だけ確認する
python3 beat_sync.py --music song.mp3 --dry-run
```

### オプション

| オプション | 説明 | 既定値 |
|---|---|---|
| `--music` | 楽曲ファイル（必須） | — |
| `--clips` | 素材フォルダ | — |
| `--out` | 出力ファイル | `output.mp4` |
| `--aspect` | 画面比率 `16:9` / `9:16` / `1:1` / `4:5` | `16:9` |
| `--fps` | フレームレート | `30` |
| `--beats-per-cut` | 何拍ごとにカットするか（1=毎拍、4=1小節） | `2` |
| `--min-cut` | これより短いカットは結合する（秒） | `0.25` |
| `--start` / `--duration` | 曲のどこから何秒使うか | 全尺 |
| `--order` | `shuffle`（ランダム）/ `sequential`（ファイル名順） | `shuffle` |
| `--seed` | shuffle の乱数シード（変えると別パターンになる） | `0` |
| `--flash` | カット頭に白フラッシュ | なし |
| `--zoom` | 各カットでゆっくりズームイン | なし |
| `--fade-out` | 終わりの音声フェードアウト（秒、0で無効） | `1.0` |
| `--bpm` | BPM を手動指定 | 自動推定 |
| `--offset` | ビート位置を全体にずらす（秒） | `0` |
| `--no-grid` | 一定テンポのグリッド補正をしない | なし |
| `--beats-json` | 検出したビートを JSON で保存 | — |
| `--dry-run` | 書き出さずにカット位置だけ表示 | — |

## 仕組み

1. ffmpeg で音声を読み込み、メル帯域のスペクトルフラックスから「音の立ち上がり（オンセット）」の強さを計算
2. 自己相関でテンポ（BPM）を推定し、動的計画法でビート位置を検出
3. テンポが一定の曲では、曲全体に等間隔のグリッドを当てはめて誤差を補正（多くのポップス・EDM で数ms精度）
4. ビート位置を出力動画のフレーム番号に丸めてカット位置を決定（長くなっても音ズレしない）
5. 各カットに素材を割り当てて比率に合わせてクロップし、つなげて楽曲を重ねる

素材が短い場合はループ、画像は静止画として使います。

## うまくいかないとき

- **テンポが倍/半分になる**：表示された BPM が実際の倍や半分なら `--bpm 128` のように指定するか、
  `--beats-per-cut` で調整してください。
- **カットが少し早い/遅い**：`--offset 0.03`（遅らせる）や `--offset -0.03`（早める）で微調整できます。
- **テンポが途中で変わる曲・生演奏**：グリッド補正は自動で無効になりますが、精度が落ちることがあります。
  `--no-grid` で補正を明示的に切ることもできます。
